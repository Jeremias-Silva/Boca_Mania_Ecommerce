## 📌 About the Project

**Boca Mania** is a robust and responsive e-commerce platform designed to connect fans with club merchandise. The project covers everything from product catalog management to a complete checkout flow, focusing on a fluid user experience (UI/UX), modern layouts, and high performance.

This ecosystem was built from scratch, applying web development best practices, separation of concerns, and secure data management.

---

## 🚀 Key Features

*   **Dynamic Product Catalog:** Browse by categories, advanced filtering, and real-time search.
*   **Interactive Shopping Cart:** Seamlessly add, remove, and update item quantities with automatic total calculations.
*   **User Authentication:** Secure login, registration, and credential recovery systems.
*   **Administrative Dashboard:** Internal interface for inventory management, order tracking, and user control.
*   **Responsive Design:** Fully optimized interface for mobile devices, tablets, and desktops.

---

## 🛠️ Technologies Used

The project was developed using the following technologies and frameworks:

*   **Backend:** Python & Django Framework (MVT Architecture, ORM, and database management).
*   **Frontend:** HTML5, CSS3 (Modern layouts and custom styling), and JavaScript for dynamic interactions.
*   **Deployment/Hosting:** Render.
*   **Environment Management:** Virtualenv & Pip.
